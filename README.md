# 鼠下快传 MouseBridge

让一套键鼠在**两台 Windows 电脑**之间自由穿梭：鼠标推过屏幕边缘即可控制对端电脑，
`Ctrl+C` 复制的文字/图片/文件在另一台电脑直接 `Ctrl+V` 粘贴，还可以把资源管理器里的
文件**拖到屏幕边缘**直接投递到对端。光标光环颜色实时指示"当前控制的是谁、在传什么"，
传输记录与后台日志可随时在一个独立窗口里查看。

单文件、免安装：

| 包 | 体积 | 说明 |
|---|---|---|
| `MouseBridge-1.7.0-win-x64.exe` | ~64 MB | 自包含 .NET 8 运行时，拷过去双击就能用（Win10/11 推荐） |
| `MouseBridge-1.7.0-net8-x64.exe` | ~1 MB | 轻量版，需先装 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0) |
| `MouseBridge-1.7.0-win7-32bit.zip` | ~1 MB | **Windows 7 SP1 / 32 位系统版**（.NET Framework 4.8），见下节 |

> 三个包都在本仓库的 **[Releases](../../releases)** 页，`md5.txt` 与之一并附上，下载后可比对校验。

## 零、Windows 7 / 32 位系统怎么装

.NET 8 从 .NET 6 起就把最低系统要求提到了 Windows 10 1607，**在 Win7 上根本起不来**（不是配置问题）。
所以另外出了一份 .NET Framework 4.8 版（微软最后一个支持 Win7 SP1 的运行时）：

1. 解压 `MouseBridge-1.7.0-win7-32bit.zip`，**整个文件夹**拷到目标电脑（不能只拷 exe，同目录的 dll 是必需的）；
2. 目标机需要有 **.NET Framework 4.8**：
   - Win10 1903 及以上：已内置，直接可用；
   - Win7 SP1 / 8 / 8.1：先装一次离线包（约 110MB），<https://dotnet.microsoft.com/download/dotnet-framework/net48>；
3. 双击 `MouseBridge.exe` 即可。

> 包内文件名**全部是英文**（说明文件叫 `ReadMe.txt`）。这是刻意的：Win7 的资源管理器
> 不认 zip 的 UTF-8 文件名标志，中文名解压出来会变成乱码，所以一律用 ASCII 名。

这一版是 **AnyCPU**：32 位系统上自动以 32 位运行，64 位系统上以 64 位运行，一个包通吃。
功能与界面和 Win10/11 版完全一致，只有两点系统差异：

- Win7 没有 Segoe Fluent / MDL2 字体，所以界面里的图标**全部用矢量路径绘制**（不用字体字形，否则显示成方框）；
- Win7 的 SChannel 要支持 TLS 1.2 需要系统补丁 **KB3140245**。开着 TLS 连不上时，
  在「连接」页把「TLS 加密」取消勾选即可 —— 身份验证仍然由连接密码保证。

## 一、快速开始（两台电脑各 3 步）

1. **拷贝** `MouseBridge.exe` 到两台电脑（U 盘/网络共享均可），双击运行。
   > 全新编译的 exe 首次运行会弹一次 Windows 防火墙授权，点「允许」（或用连接页的「防火墙放行」按钮）。
2. 打开设置页 → **连接**，按这一页从上到下填三行就够了：
   - **本机名称**：默认就是本机的设备名，想改就点进去改（只是让对方一眼认出这台机器）；
   - **对端地址**：**任意一台**填上对方的 IP 就行 —— 两台都会主动拨号，谁填谁能连上；
     不知道对方 IP 就点「扫描」，扫到就自动填进来；
   - **连接密码**：两台必须一致。任一台点「生成」拿到一串随机密码，照着在另一台填一样的即可。
3. 在主控端「屏幕与切换」里选择对端屏幕的方位（比如对端在**右侧**）。

之后：把鼠标从主控端推向右侧边缘 → 控制权切到对端（推回对端左边缘即返回）。

> **角色只决定"谁控制谁"，不再决定"谁能发起连接"** —— 上一版只有被控端会拨号，
> 坐在主控端点「连接」毫无反应，这就是那个毛病的根因。
> 万一两台都填成了同一种角色，软件会按机器名自动协商出谁控制谁，不会连不上（连接成功后提示里会说明）。

## 二、功能与用法

| 功能 | 操作 |
|---|---|
| 鼠标/键盘跨机 | 鼠标推过两屏相接的边缘即切换；再推回边缘即返回。**鼠标在哪台，敲的键就进哪台** |
| 文字/图片跨机复制 | A 机 `Ctrl+C` → B 机 `Ctrl+V`（自动同步剪贴板） |
| 文件跨机复制 | A 机资源管理器选中文件 `Ctrl+C` → B 机资源管理器 `Ctrl+V` |
| 大文件按需传输 | 超过"预接收上限"的文件：在 B 机按 `Ctrl+V` 才开始传输（带进度条） |
| 拖拽投递 | A 机拖着文件顶到朝向 B 机的屏幕边缘 → 自动传输到 B 机指定文件夹 |
| 传输进度 | 光标光环外圈进度弧 + 文字百分比；右下角提示条同步显示 |
| 传输记录 / 日志 | 托盘菜单 → **传输记录与日志…**：当前进度、历史记录、后台日志一屏看完 |

## 三、光标指示器图例

光环颜色表示**当前状态**：

- ⚪ 灰色：未连接
- 🟢 绿色：控制本机
- 🟠 橙色：正在控制对端（主控端视角）
- 🔴 红色：本机正被对端控制（被控端视角）／此处不能投递
- 🟣 紫色旋转虚线：正拖着文件（可跨屏投递）
- 🟢 青绿色：松手即可保存到高亮文件夹
- 🔵 青色：正在传输文件——外圈另有一条实心**进度弧**叠加在压暗的光圈上，

文字说明默认挂在**光圈右侧**、与光圈垂直居中，贴近屏幕右边缘时会自动翻到左侧，不会被屏幕边切掉。
颜色 + 文字是两条独立通道：只瞄一眼颜色就知道"现在是谁在控制"，需要细节时再看文字。

- `本机` / `控制 XXX` / `被控中·来自 XXX`：当前键鼠归属
- `拖拽中 · N 项` + `大小 → 松开左键投给 XXX`：确认文件已选中、松手会去哪
- `松手保存 → 文件夹名` / `此处不能投递`：松手能不能保存
- `传输中` + `接收 3 个文件 42%`：传到哪了

徽标（光环右上角小圆点）表示**是否有待使用的物料**：

- 🟡 黄点：对端发来的文件等待接收
- 🟢 绿点：文件已接收就绪，`Ctrl+V` 即可粘贴
- 🔵 蓝点：剪贴板已同步（文字/图片）

> 光环大小可在"设置 → 指示器"里用滑块实时调整（24~96px），拖动即刻生效、不用保存；
> 那里的"显示光标光环""显示文字状态""进度弧""物料徽标"开关同样是勾一下立即生效。

## 四、传输记录与运行日志

托盘图标右键 → **传输记录与日志…**（或设置页"指示器"里的按钮，命令行 `MouseBridge.exe --history`）。

窗口分三块：

1. **当前状态**：连接状态、对端、角色，以及正在进行的传输——进度条、已传/总量、速度、剩余时间；
2. **传输记录**：每次收/发的时间、方向、对端、文件数、大小、耗时、结果、落盘位置。
   记录持久保存在 `%APPDATA%\MouseBridge\transfers.jsonl`，重启后仍在；
   支持**导出 CSV**（Excel 可直接打开，带 BOM 不乱码）、**清空记录**；
   双击一条记录可跳到对应的文件夹；
3. **运行日志**：后台日志实时滚动（可按级别过滤、可关掉自动滚动），一键打开日志目录。

## 五、网络连接

- **局域网**（推荐）：自动发现 + 自动连接，无需配置。端口：TCP 39501 + UDP 39500。
- **两端对称**：两台电脑**都在监听、也都能主动拨号**。谁填了地址/扫到了对端谁就连上去，
  角色只决定键鼠方向。同时互拨撞出两条链路时，两端会按同一套排序键（计算机名+显示名）
  各自保留同一条、丢掉另一条，不会出现"两边各连一条"的错乱。
- **跨路由器 / 广播被隔离**：「扫描」除了各网段定向广播，还会对本机 /24 及相邻两个第三段
  网段做 450ms TCP 端口探测（覆盖 `192.168.1.x ↔ 192.168.2.x` 这种双层路由组网）。
  还扫不到就直接手填对方 IP —— 对方界面下方「本机地址」那行就是要填的值。
- **不会把自己当对端**：扫描结果与本机地址比对后会过滤掉自己；手填的地址若等于本机 IP，
  会明确提示并拒绝（否则会"自己控自己"）。
- **安全**：默认开启 TLS 加密（自签名证书 + 首次连接指纹钉扎）+ HMAC 密码挑战认证。
  连接密码就是你的凭证，请设置足够强度；密码为空时同网段任何装了本软件的机器都能连上，
  连接页会给出警告。
- 防火墙：首次监听时 Windows 会弹窗，允许即可；或在设置页点「防火墙放行」一键加规则。

## 六、设置项说明

- **连接**：本机名称、对端地址（IP 或 IP:端口）、连接密码（可一键生成）、
  本机角色、跨机热键、TLS、自动发现、TCP 端口、立即重连、防火墙放行。
- **屏幕与切换**：对端方位（带预览图）；"顶住边缘延迟切换"毫秒数（防误触，推荐 200~500）；
  Scroll Lock 键锁定/解锁当前屏幕。
- **剪贴板与文件**：文本/图片/文件同步开关；自动预接收及上限（默认 512MB）；
  单次剪贴板大小上限；拖拽投递接收目录（桌面/下载/自定义）及"完成后打开文件夹"。
- **指示器**：开关、光环大小（滑块拖动**实时生效**，24~96px）、文字状态/进度弧/物料徽标开关，
  以及"打开传输记录与运行日志"入口。开关与滑块都是勾一下/拖一下立即作用于真实光环，不必先保存。
- **高级**：开机自启、日志级别、打开日志文件夹、已知限制说明。

## 七、实现原理（简述）

- **输入捕获**：主控端用低级钩子（WH_MOUSE_LL / WH_KEYBOARD_LL）捕获物理输入；
  切换到对端后吞掉本地输入并经 TCP 转发；被控端用 `SendInput` 注入。
  自注入事件带魔数标记（extraInfo）防止钩子回环。
- **边缘切换**：主控端维护"对端虚拟光标"坐标，进对端屏幕后按物理增量驱动；
  回到对端相接边缘时切回本机（带 4px 防抖死区，避免反复横跳）。
- **剪贴板**：`AddClipboardFormatListener` 监听；内容签名回声抑制防两机循环转发。
  文件走"清单先行 + 按需/预接收传输 + 暂存区 + 写入本地剪贴板"，粘贴即原生 Explorer 复制。
- **拖拽投递**：检测 Explorer 拖拽窗口（SysDragImage）+ 鼠标顶边即触发，
  读取资源管理器当前选中项开始传输（用 ESC 结束本地拖拽）。
- **传输协议**：长度前缀帧（JSON 头 + 二进制载荷）；文件 256KB 分块、有界队列背压；
  磁盘读写走独立写线程，大文件传输不会卡住鼠标/键盘注入。
- **传输台账与日志**：每次传输在 `transfers.jsonl` 追加"开始/结束"两行 JSONL，
  读回时同 Id 后写覆盖先写、仍处于"进行中"的标记为"已中断"；日志查看用增量读取（只读新增字节）。
- **光标光环**：无边框透明置顶窗口，`SizeToContent.Width` 按内容定宽，
  每 15ms 跟随光标（物理像素按 PerMonitorV2 转 WPF 逻辑像素，跨不同 DPI 显示器也准）。

## 八、已知限制

- 注入输入无法作用于**管理员权限**窗口（UIPI 限制）。如需远控提权程序，
  请让 MouseBridge 也以管理员身份运行。
- 跨机打字是原始键码转发：**中文输入法需在对端电脑上切换**；长中文建议剪贴板粘贴。
- 拖拽投递仅支持资源管理器窗口内拖拽（桌面拖拽请用 Ctrl+C）。
- 跨机"剪切"实际按复制处理（对端得到副本，源文件不删除）。
- 每台电脑仅支持一块"虚拟大屏"（多显示器会被当作整体）。
- Win7 版另有两处系统限制：TLS 1.2 依赖 KB3140245 补丁；系统没有 Segoe Fluent/MDL2 图标字体
  （界面已全部改用矢量图标规避）。

## 九、故障排查

| 现象 | 处理 |
|---|---|
| 点「连接」没反应 | ① 看顶部状态条是否显示"正在连接 x.x.x.x …"；② 地址是不是**本机自己的 IP**（会明确提示）；③ 点「扫描」看能不能找到对端；④ 两台都点「防火墙放行」 |
| 一直"未连接" | ① 密码是否一致？② 对方软件是否在运行？③ 被控端填主控端 IP 试试；④ 防火墙放行 |
| 连上了但鼠标切不过去 | 主控端"屏幕与切换"的方位是否与实际摆放一致；被控端屏幕分辨率是否识别正确 |
| 提示"两端角色相同，已自动…" | 两台填成了同一种角色。已自动协商出谁控制谁，要用原来的方向就在设置里改回一主一从 |
| Ctrl+V 没反应 | 光标徽标是否黄色（文件较大仍在接收）？等绿点出现再按 |
| 打字打到了对面 | 鼠标在对端屏幕上时键盘会跟着走（这是 KVM 的正常行为）。把鼠标推回本机边缘即可 |
| 首次连接报证书变化 | 对端重装过软件：在被控端设置里点"重置对端信任（证书指纹）" |
| 看日志 | 托盘右键 →「传输记录与日志…」，或 `%APPDATA%\MouseBridge\logs\mb-日期.log` |
| 想查某次传了什么、存到哪 | 同上窗口的"传输记录"页；双击一条可跳到对应文件夹 |
| 光环文字被屏幕右边切掉 | 已自动翻到左侧；若仍不合适，在设置里把光环调小或关掉文字 |

## 十、构建与自检（开发者）

项目是**双目标**：`net8.0-windows`（自包含单文件，Win10/11）与 `net48`（.NET Framework 4.8，
Win7 SP1 / 32 位）。两个目标共用同一套源码，API 差异全部收敛在
`MouseBridge/Core/Compat.cs`（`MathX.Clamp` / `Monotonic.Ms` / `Hex.Of` / `Hashing.Sha1` /
`Rand.Bytes` / `Crypto.*` / `AppExe.Path` / `TaskEx.WithTimeout|WithToken` / `StreamEx.ReadAsync` /
`ChannelEx.ReadAllEx` / `SslEx.*` / `Str.Has`）与 `Core/IsExternalInit.cs`（记录类型所需的空壳）。
**新增代码请一律用这些兼容层，不要直接调 .NET 8 专有 API。**

```bash
# 两个目标分别编译
dotnet build -c Release -f net8.0-windows
dotnet build -c Release -f net48

# 自检（协议/认证/剪贴板/文件传输/传输台账/日志/本机地址识别，共 18 项，不碰真实桌面）
dotnet run -c Release -- --selftest

# 冒烟（真实启动 5 秒自动退出）
dotnet run -c Release -- --smoke

# 一次性打包三个交付包到 dist/ 并生成 md5.txt
python tools/package.py

# 真实双进程互连测试（同机起两个实例，覆盖 4 种组网/角色/去重/TLS 组合）
python tools/pair_test.py                # net8
python tools/pair_test.py --tf net48     # Win7/32 位兼容版

# 出图 / 验收：设置页各页、光环各状态、传输记录窗口
python tools/shots.py all            # → shots/00_界面总览.png、shots/01_光环状态总览.png
python tools/halo_slider_test.py     # 端到端验证"拖滑块 → 真实光环尺寸变化"
python tools/legend_hover_test.py    # 端到端验证"悬停颜色图例 → 左侧预览演示该状态"
```

其它命令行开关：`--settings [--tab N]`（直达设置某页）、`--history`（直接打开传输记录窗口）、
`--preview-halo`（光环状态轮播，出图用）。

测试用环境变量（正常使用不需要）：
`MB_DATA_DIR=<目录>` 覆盖数据目录、`MB_ALLOW_SELF=1` 允许连接本机地址
（同机双实例自测必须开，否则会被"不许连自己"的保护挡住）。

> 打包务必**不要**开启 `InvariantGlobalization`：它会让 WPF 字体缓存初始化抛
> `CultureNotFoundException`，中文与多字体回退直接崩。

> 截图脚本调 `SetWindowPos` 前**必须**声明 `argtypes`。不声明时 ctypes 按 32 位 int 传参，
> `HWND_TOPMOST(-1)` 会被零扩展成 `0x00000000FFFFFFFF`（不是合法 HWND），函数返回 0、
> 窗口不置顶，截出来全是压在上面的 IDE 画面。声明后 `SetWindowPos(hwnd, -1, ...)` 才真正生效。

技术栈：C#（WPF + WinForms），双目标 .NET 8 / .NET Framework 4.8，全部 P/Invoke 自包含，无第三方 UI 库。
